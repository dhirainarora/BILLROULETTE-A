# Bill Roulette Android

Android-native project based on the current BILLROULETTE web product.

Application ID: com.billroulette.a
Target SDK: 35
Minimum SDK: 26

Flow: Home → Setup → Fate Animation → Reveal → Results, plus History, Settings, currencies, modes, sharing, sound, and haptics.

Build the `app` module with Gradle/Android tooling before release.
